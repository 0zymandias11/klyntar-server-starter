# klyntar-server-starter

A learning-oriented starter that documents migrating a Go server from REST (chi) to gRPC.

## Contents

- [GRPC_GUIDE.md](GRPC_GUIDE.md) — walkthrough of the REST → gRPC migration, including a from-scratch gRPC setup section.

## Who this is for

Developers with some Go experience who want a practical, commit-driven reference for standing up a gRPC service: wiring protobufs, generating code, running the server, and comparing patterns against an equivalent REST implementation.

## Getting started

Clone the repo and open [GRPC_GUIDE.md](GRPC_GUIDE.md) — it's structured to be read top-to-bottom.

```bash
git clone https://github.com/0zymandias11/klyntar-server-starter.git
cd klyntar-server-starter
```
